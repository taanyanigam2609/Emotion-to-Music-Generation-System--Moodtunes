System Architecture

Discover the deep learning models, computer vision engines, and audio synthesizers running under the hood of MoodTunes.

The Generative Core

MoodTunes operates on a custom-trained Conditional Long Short-Term Memory (LSTM) neural network. Trained on the curated EMOPIA dataset, the model features 512-unit memory cells capable of understanding complex musical phrasing over time. By translating human psychological states (Valence and Arousal) into dense mathematical embeddings, the network autonomously predicts the optimal sequence of notes, velocities, and tempos to directly mirror your current mood.

Technology Stack

Machine Learning

TensorFlow and Keras power the sequential network. DeepFace and OpenCV's Haar Cascades handle millisecond-level facial recognition.

Backend Infrastructure

A robust Python Flask REST API handles data sanitization, algorithmic failsafes, and zero-crash neural routing.

Audio Synthesis

Tone.js natively synthesizes audio in the browser, translating raw MIDI arrays into studio-quality FM, AM, and Pluck waveforms.

Frontend Interface

Vanilla JS and HTML5 Canvas ensure zero-latency UI updates, real-time waveform rendering, and client-side image compression.

Zero Data Persistence

Privacy is hardcoded into our architecture. Visual inputs are processed entirely in active memory (RAM) strictly for emotional vector extraction and are instantly destroyed. We do not store, log, or train on any user biometric data.
